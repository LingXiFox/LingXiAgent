# 1. 快速上手 (Getting Started)

LingXiAgent 可以在 macOS（Apple Silicon M系列及 Intel 芯片）和主流 Linux 发行版上原生运行。安装只需一条命令，即可完成环境探测、可执行文件安装与 Shell 变量配置。

步骤一：一键自动安装

$ curl -fsSL https://agent.lingxifox.cn/install.sh | bash

步骤二：刷新终端并首次启动

# 刷新终端配置环境（或重新打开一个终端窗口）
$ source ~/.zshrc

# 立即启动终端交互界面
$ lingxiagent
提示： 首次启动时若未配置任何账号，可在 TUI 中输入 /auth 或在命令行执行 lingxiagent auth login [provider] 快速登录。

# 2. 终端 TUI 使用指南 (TUI Usage)

LingXiAgent 具备业界领先的 60FPS 原生终端界面，采用双栏式布局，支持思考流折叠、代码 Patch 高亮审查与键盘一键导航。

常用快捷键

切换代理模式 (Normal / Plan / Boost) Tab / Shift+Tab
中断当前思考或工具流 Ctrl + C
展开 / 折叠思考流 (Thinking) Enter / 鼠标点击
滚动查看历史会话 PageUp / PageDown

Slash 快捷命令

  • /model — 唤起模型选择弹窗，支持在官方订阅模型与自定义 API 模型间毫秒切换。
  • /auth — 查看已登录账号状态、额度及重新登录。
  • /clear — 清理当前会话上下文并保留核心项目知识库。
  • /cost — 查看本次会话的 Token 消耗、缓存命中率及累计费用预估。

常用 CLI 实用子命令

# 自动审查当前 Git 工作区未提交改动:
$ lingxiagent review
# 系统环境、网络连接、凭据安全健康自检:
$ lingxiagent doctor
# 管道输入与无头批量任务执行:
$ git diff | lingxiagent exec "生成本次变更的英文规范 commit message"
# 恢复上次历史中断的会话:
$ lingxiagent resume --last

# 3. 提供商与认证体系 (Providers & Auth)

LingXiAgent 确立了“官方内置渠道与自定义渠道物理隔离”的核心架构。内置渠道无需也不允许写入用户配置文件，确保升级平滑无污染。

官方订阅登录命令 (OAuth 认证)

# 1. 登录 OpenAI ChatGPT Plus / Pro 订阅:
$ lingxiagent auth login openai-codex
# 2. 登录 Claude Code 订阅:
$ lingxiagent auth login anthropic-claude-subscription
# 3. 登录 Google Antigravity / Gemini Code Assist:
$ lingxiagent auth login antigravity

自定义 API 提供商配置 (~/.lingxiagent/providers.json)

若想接入 DeepSeek、硅基流动、Ollama 等第三方 API，在配置文件中添加即可：

{
  "version": "1.0",
  "providers": [
    {
      "id": "deepseek",
      "name": "DeepSeek 官方",
      "options": {
        "baseURL": "https://api.deepseek.com/v1",
        "apiKey": "sk-your-deepseek-api-key"
      },
      "models": [
        { "id": "deepseek-chat", "name": "DeepSeek V3" },
        { "id": "deepseek-reasoner", "name": "DeepSeek R1" }
      ]
    }
  ]
}

# 4. 反检测伪装与客户端指纹 (Client Fingerprint)

针对 Cloudflare、Akamai、DataDome 等企业级防爬与人机验证系统，LingXiAgent 内置了独有的动态宿主感知防封机制。

为什么我们拒绝生硬硬编码 Linux / Windows UA？

如果客户端运行在 macOS Apple Silicon 上，底层的 TCP 初始窗口大小与 TLS JA3/JA4 握手特征是纯正的 Darwin。一旦 HTTP 请求头假冒为 Ubuntu 22.04 或 Windows AMD64，WAF 会立刻根据协议栈矛盾判定为伪造流量，导致账号触发封锁或人机验证。

# 5. 扩展能力与 MCP 协议 (Extensions & MCP)

LingXiAgent 具备完整的 Model Context Protocol (MCP) 支持，可以一键连接数据库、浏览器自动化、文档分析及各类自定义微服务。

配置文件 (~/.lingxiagent/mcp.json)

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/lingxifox/Projects"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_xxx" }
    }
  }
}

# 6. 常见问题与排错 (Troubleshooting)

Q1: 安装后提示 command not found: lingxiagent？

请确认你的 Shell 配置文件中包含 export PATH="$HOME/.lingxiagent/bin:$PATH"，并执行 source ~/.zshrc（或重新打开终端）。

Q2: TUI 界面字符乱码或布局错位？

建议使用支持 TrueColor 及现代终端协议的终端模拟器，如 Ghostty、WezTerm、iTerm2 或 Kitty，并确保终端字体安装了支持 Nerd Font 或常见等宽编程字体（如 JetBrains Mono、Fira Code）。
